### 📋 Sobre o Projeto

Este repositório reúne a estrutura inicial e os padrões de arquitetura desenvolvidos em sala de aula pelo **Prof. Helifaz Viana** em conjunto com os estudantes da área de **Desenvolvimento de Sistemas**.

O objetivo principal é criar um ambiente realista de treinamento para o **SAEP (Sistema de Avaliação da Educação Profissional e Tecnológica)**, permitindo que a turma pratique o ciclo completo de construção de software antes da avaliação oficial — desde o entendimento das regras de negócio e modelagem de dados até a implementação, testes e versionamento de código.

---

### 🎯 Objetivos Pedagógicos e Técnicos

- **Simulação Realista:** Reproduzir a estrutura, os critérios de qualidade e o ritmo de entrega exigidos na prova prática do SAEP.
- **Construção Colaborativa:** Incentivar a cultura de desenvolvimento em equipe, utilizando Git e GitHub para controle de versão, branches e revisão de código.
- **Padronização e Boas Práticas:** Estabelecer uma arquitetura limpa e organizada que sirva de referência rápida para consultas e estudos individuais.
- **Visão de Produto:** Integrar requisitos funcionais, persistência de dados, regras de negócio e usabilidade em uma entrega coesa.
